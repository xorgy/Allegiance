# Native IGC callback inventory

Generated by `python src/native/audit_callbacks.py`. An override only establishes
that a callback is wired; it does **not** establish equivalent behavior. See
[the audit and work queue](native-equivalence.md) for semantic findings.

Tables list declared callback names (overloads grouped). The shared AttachSite
base is listed separately for both adapters. Defaults are reported from source;
a default may be intentional, but still needs a semantic disposition.
